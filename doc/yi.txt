一、 作品題目 (Topic)
主標題： 潮汐發酵誌：流動的里海記憶 (Liquid Satoumi: The Fermented Intertidal Archive) 
副標題： 台灣東岸潮間帶生態知識與傳統釀造之跨域調酒設計 
文資設計專家觀點： 主標題點出「時間（發酵）」與「空間（潮汐）」 ，副標題直接回應「永續跨域設計」的本質——將原住民傳統生態知識（TEK）與當代精緻調酒（Mixology）進行物質與文化上的跨界整合 。本次修訂更將物質版圖從「海岸植物/穀物發酵」延伸至「海洋動物性風味（黑潮魚類與潮間帶螺貝）」，使整體里海生態鏈的物質轉譯更具備一體性。 
二、 SWOT / TOWS 交叉戰略分析
為了在「永續跨域類」脫穎而出，我們必須將環境、文化、技術進行矩陣分析 ： 
內部 / 外部環境
優勢 (Strengths - S)
劣勢 (Weaknesses - W)

1. 獨特的文化敘事（東岸傳統女性的潮間帶生態智慧） 。 

2. 天然風味屏障（太平洋海鹽與礁岩海菜的天然鹹鮮，市場罕見） 。 

3. 多層次的海洋生態旨味（螺貝類的礦物感與黑潮煙燻魚乾的木質煙燻味，建立極高風味辨識度）。
1. 野生採集具季節性，原料供應不穩定 。 

2. 傳統野生發酵（小米酒/芋頭酒）風味較難標準化 。 

3. 潮間帶生態敏感度高，過度商業化易遭批判 。 

4. 動物性原料（螺貝、魚類）處理不當易產生魚腥味（Off-flavor），考驗技術穩定度。
機會 (Opportunities - O)

1. 全球「里海精神（Satoumi）」與慢食運動（Slow Food）浪潮興起 。 

2. 大賽鼓勵結合現代科技與創意轉譯 。 

3. 當代酒吧市場對「在地風土（Terroir）」調酒需求極高 。 
【SO 成長戰略】

利用「流動的里海」概念，將潮間帶採集與黑潮漁業民俗包裝成故事線，乘著全球慢食與永續浪潮，直擊評審對文化深度與當代轉譯的偏好 。 
【WO 扭轉戰略】

導入現代酒吧的**「科學澄清技術（如離心、牛奶澄清）」 與 「控溫發酵」** ，並結合「低溫減壓蒸餾（Rotovap）」與「油脂排比法（Fat-washing）」，將魚乾與螺貝的風味去腥、去油、精準萃取，將不穩定的原物料劣勢轉化為技術創新的亮點 。 
威脅 (Threats - T)

1. 氣候變遷導致海岸線生態劣化、採集點消失 。 

2. 菸酒管理法規對非典型釀造流通的限制 。 

3. 容易被批判為對原住民傳統文化的「流於表面掠奪」 。 
【ST 防禦戰略】

不走大眾商用路線，而是與在地部落/社區建立「利益共享與採集契作」機制 。在漁獲與螺貝採集上遵從在地傳統季節禁忌（如飛魚汛期規範、潮間帶休養期），強調這是一項「文化保存計劃」而非純商業飲品，防範文資流於表面的批評 。 
【WT 消除戰略】

將定位從「大宗量產的酒商品」提升為**「限量版文化體驗儀式套組（Experience Kit）」** 。減低對採集總量的依賴，同時規避大規模菸酒通路的法規限制 ，並將海鮮類風味調酒定位為無法被複製的「季節限定珍藏」。 
三、 核心概念 (Concept)
本作品是一場「以舌尖為媒介的生態文資保存行動」 。 
我們將台灣東岸潮間帶由來已久的「女性採集民俗」與「傳統芋頭/小米發酵智慧」視為非物質文化資產 。本設計不使用任何化學利口酒 ，而是全面盤點海岸線風土：除了採集礁岩海菜的微鹹、日曬海鹽的晶體風味 ，更將物質版圖延伸至黑潮魚群（如飛魚、鰹魚）經傳統柴薪煙燻後的木質調性，以及手採螺貝類的「岩礁旨味（Umami）」。 基底則揉合東部傳統作物（芋頭與小米）的現代改良發酵液 。 
透過現代調酒的「風味澄清（Clarification）」與「低溫減壓蒸餾」技術 ，將原本帶有油脂且渾濁的傳統釀造酒與海洋動物萃取液 ，轉化為如太平洋海水般清澈、卻飽含海潮鮮香、柴燻營火與海風氣息的「流動里海液體」 。這不僅是一杯調酒，更是串聯「採集者、釀造者、飲用者」的跨領域永續生態鏈 。 
四、 目標用戶 (Target Users)
市場受眾：精緻餐飲（Fine Dining）與當代高端酒吧消費者 這群消費者願意為「故事」、「風土」與「永續生態價值」支付溢價 。他們尋求的不是酒精帶來的宿醉，而是透過一杯酒體驗台灣東海岸的潮汐、黑潮汛期與島嶼記憶 。 
生態受眾：地方創生倡議者與永續飲食實踐者 關注里海精神、慢食運動的人群 。這杯調酒融合了採集民俗與黑潮漁業的脈絡，成為他們向大眾推廣海岸線生態保育與原住民傳統生態知識（TEK）的流動載體 。 

為了滿足高端酒吧與精緻餐飲（Fine Dining）消費者對於「故事、風土與永續價值」的極致追求 ，實體展演時的「限量版文化體驗儀式套組（Experience Kit）」不能只是流於裝飾，而必須成為生態文資的延伸 。 
面對這杯「如太平洋海水般清澈，卻飽含海潮鮮香與柴燻營火氣息」的衝突性液體 ，我們的視覺與器皿設計核心策略應是：用極致粗獷、帶有手感溫度的自然物質，來反襯現代科技澄清後的精緻液體。 
以下是為這款調酒量身打造的實體展演與視覺物件規劃：
一、 核心器皿：衝突美學的物質載體
杯體：極薄薄吹手工波紋硝子（玻璃杯） 為了展現透過現代調酒技術「澄清（Clarification）」後的清澈酒體 ，必須選用透光度極高、質地極薄的手工玻璃杯。杯身帶著隱晦的職人吹製波紋，當光線穿過清澈的酒體，會在桌面上投射出如太平洋日光折射般的流動水紋。 
杯墊座：潮間帶黑火山岩與咾咕石底座 玻璃杯不直接著地，而是嵌在一個手工鑿刻的東海岸黑色火山岩（或經合法整理的粗糙礁岩塊）底座上。這回應了傳統女性手採螺貝、海菜的「岩礁環境」 ，當飲用者拿起玻璃杯時，手指會先觸碰到底座粗糙、冰涼且帶有孔隙的岩石質地，與極薄玻璃的細緻感形成強烈對比。 
二、 儀式套組外盒與視覺物件：「採集文資檔案室」
體驗套組的外盒應被設計得像是一個「田野考古檔案盒」，呼應「潮汐發酵誌（Archive）」的概念 。 
外盒材質：煙燻碳化木盒與構樹皮紙
外盒採用經過輕微火烤、帶有微弱碳化焦香的木盒，視覺上暗示了黑潮魚群（飛魚、鰹魚）在部落中接受柴薪煙燻的工藝脈絡。內襯則使用台灣在地手工構樹皮紙或帶有原生纖維的粗糙紙質，並印上採集當天的「海岸座標、潮汐時間、發酵天數」。
緩衝防震：未精製的傳統植物纖維（如手抄馬尼拉麻或月桃葉鞘）
不使用任何塑膠或現代發酵包材，盒內固定器皿的緩衝材直接使用東海岸常見的傳統工藝纖維（如粗編的小米稻草、月桃葉鞘，或是帶有堅韌質感的馬尼拉麻/黃麻粗線）。飲用者在開箱時，視覺與嗅覺會先被帶入原始的土地與植物氣息中。
盒內風土鋪墊：日曬海鹽結晶床 套組內部開槽的底部，鋪墊著一層厚厚的、未精製的東海岸大顆粒日曬海鹽結晶 。器皿就像是直接從海鹽堆中被「挖掘」出來一樣，點出海鹽在發酵與保存中的關鍵角色 。 
三、 侍酒儀式（Serve Ritual）與五感觸發
這杯酒的精髓在於「視覺極度清澈，嗅覺與味覺卻極度濃烈」 。在 Fine Dining 或大賽展演的現場，侍酒儀式應分為兩階段： 
封存的煙燻海風（嗅覺先行）：
酒液在倒入玻璃杯後，會先扣上一個由煙燻漂流木製成的微型木蓋。侍酒師在桌邊使用高溫噴槍，輕微炙烤木蓋頂端的一小片「煙燻飛魚乾碎屑」或「傳統柴薪」，讓一縷帶有油脂香氣的木質海洋煙燻緩緩飄散在飲用者面前。
解封的里海液體（視覺與味覺的衝擊）： 當木蓋被移開，飄散的煙燻散去，展現在飲用者眼前的，卻是一杯毫無雜質、透明如水的液體 。當他們帶著預期是強烈海鮮味的心理喝下時，現代發酵芋頭與小米的酸甜、澄清螺貝的細緻Umami、以及海菜的微鹹 ，會在舌尖爆發開來。
